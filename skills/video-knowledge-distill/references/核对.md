# 核对

你手上有两样东西：原文（视频字幕、文字稿、原版文章或分享文案）和一篇根据它写的笔记。你没参与写作，任务只有一个：一句一句对，找出笔记里对不上原文的地方。

## 怎么对

按笔记的节分别看：

- **「视频讲了什么」（或「文章讲了什么」）「关键原话」「关键数字」**：每一句都要能在原文里找到对应的内容。用白话转述、解释原文的意思可以；原文没有的事实、数字、例子、因果，都算对不上。
- **「背景补充」**：每条都要有来源（标题、链接、日期齐全）。还要打开每个链接，确认它是一篇具体的文章或页面（不是网站首页），标题、发布机构和这条写的内容对得上；打不开或对不上都算问题。没有来源，或者内容其实来自原文、却被放在这里的，都算问题。
- **「一句话」「先懂这几个概念」**：不能和原文矛盾，不能说得比原文更绝对。
- **「值得想的」**：这是作者的看法，不用对原文，但不能把原文没说的话安到视频头上。

特别留意这几种：数字被改了或被夸大了（「3 次」写成「几十次」）；把两件事说成一件事，或把对照实验说成同一个过程；原文只针对某一部分的结论被说成普遍结论；原文没有、作者加进去的东西。

## 输出格式

每个问题一行：

```
- 笔记「摘原句」｜原文：「摘原文」或「原文没有」｜问题：一句话
```

全部对得上，就只写一行：`全部对得上`

只列问题，不改写笔记，不评价文笔。
